# Pricing — .gui (dotgui)

## Free — $0 forever

The entire .gui toolchain is open source and free to use. There are no paid tiers, no usage limits, and no login required.

### What's included

- **Format specification** — the .gui file format is open and unencumbered
- **@dotgui/kit** — parser, validator, renderer, linter, scorer (npm package)
- **@dotgui/cli** — `gui` command-line tool: read, write, lint, render, package (npm package)
- **@dotgui/embed** — CDN embed library for rendering .gui files in any webpage (npm package)
- **Figma plugin** — export any Figma layer as a .gui file (Figma Community)
- **dotgui skill** — `gui setup` installs the skill into your AI agents (Claude Code, Gemini CLI, Cursor, and others)

### License

All packages are open source. Source: https://github.com/dotgui/core

### Install

```
npm i -g @dotgui/cli
```

No account, no API key, no sign-up.
